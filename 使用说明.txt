MHW 竞速语音计时器 v1.2
================================

一个给《怪物猎人：世界 / Iceborne》（PC Steam 版）竞速练习用的语音计时器。
自动读取游戏内存识别任务开始/结束，用甜美少女音播报进行时长与完成时间；
带图形界面，可直接改配置、一键触发 IN-Q 重置、设置定时自动重置。

★【重要依赖：重置功能需要 IN-Q】★
  计时与语音播报：本工具独立完成，不需要任何其他东西。
  重置功能（"手动重置任务" / "定时重置"）：需要你另外安装并运行 IN-Q。
    分工是：IN-Q 负责真正把任务重置，本工具负责在合适的时机自动触发它
    （本工具直接操作游戏内存做重置，涉及对加壳游戏做逆向，无法做到）。
  所以：使用重置功能前，请先启动 IN-Q，并让界面里的"重置按键"与 IN-Q 里
  设置的快捷键保持一致（默认 F11）。不需要重置功能的话，可以完全无视 IN-Q。
  界面状态区会实时显示 IN-Q 是否在运行（绿点=已运行可用 / 红点=未运行不可用）。

【特点】
  * 任务开始/重置时播报"任务开始"，每 60 秒播报进行时长
  * 击杀目标瞬间播报"任务完成"，随后播报"用时 X 分 X 秒"
  * 兼容 IN-Q 的 F11 / F10 重置
  * 语音默认微软晓晓（zh-CN-XiaoxiaoNeural 甜美少女音，需联网），离线自动退回系统内置中文语音

【系统要求】
  * Windows 10 / 11 64 位
  * Steam 版《怪物猎人：世界》+ 冰原 DLC，版本 v15.20 或更新
  * 不需要安装 Python 或任何运行库

【使用方法】
  1. 解压整个文件夹（exe 和 config.json 必须放在一起）。
  2. 双击 MHW竞速语音计时器.exe，弹出图形界面即启动成功。
     ——先开计时器或先开游戏都可以，计时器会自动等待并连接游戏。
  3. 进任务 / 按 IN-Q 的 F11 重置后即自动播报。
  4. 退出：点界面右下角"退出"。

【界面说明】
  ● 状态区：显示游戏是否已连接、任务状态、当前用时、最近一次事件。
  ● 播报设置：播报间隔、小数位、完成补偿、是否播报开始/放弃、读条是否算新一局。
  ● 语音：选择晓晓（需联网）或系统内置，可改语音名与音调。
  ● IN-Q 重置：
      - 重置按键：选 F11 / F10（与你在 IN-Q 里设置的"重新开始/重置"快捷键一致）
      - 手动重置任务：点一下即发送该按键，触发 IN-Q 重置
      - 定时重置(秒)：填 >0 的数字后，任务进行到该秒数会自动重置（0 = 关闭）
  ● 底部：保存并应用 / 测试语音 / 退出

【配置】也可直接用记事本改同目录 config.json（改完重启程序）：
  interval_seconds            播报间隔秒数（默认 60）
  precision                   时间小数位（默认 1）
  announce_start              任务开始时是否播报
  announce_abandon            放弃/失败时是否播报
  reset_on_load               任务中"读条结束"即视为新一局（默认 true；IN-Q 重置依赖它）
                              ——打多区任务（换区有读条）请设为 false，避免换区误报
  completion_offset_seconds   完成时间补偿秒数（默认 0.40，用于对齐结算画面）
  reset_hotkey                触发 IN-Q 重置的按键（默认 F11）
  auto_reset_seconds          定时重置秒数（默认 0 = 关闭）
  tts.*                       语音引擎与音色
  texts.*                     播报文案模板

【常见问题】
  Q: 双击后 Windows 弹出"已保护你的电脑"蓝色窗口？
  A: 本程序未做数字签名（个人开发免费软件常见现象）。点"更多信息"→"仍要运行"即可。
     个别杀毒软件可能误报，请添加信任。

  Q: 为什么杀软可能误报？
  A: 本程序通过"读取游戏内存"来识别任务状态（与 HunterPie、LiveSplit 自动分段同类），
     这类行为容易被启发式引擎误判。程序只【读取】内存，不修改游戏文件、不注入、不上传任何数据。

  Q: "手动重置/定时重置"没反应？
  A: 需要 IN-Q 正在运行，且"重置按键"要和你在 IN-Q 里设置的一致（默认 F11）。
     触发时请让游戏窗口处于前台。

  Q: 没有声音 / 是机械音？
  A: 甜美少女音（晓晓）需要联网。断网时会自动退回系统内置中文语音；若系统没有中文语音包，
     可到"Windows 设置 → 时间和语言 → 语音"添加中文语音。

  Q: 只支持什么版本？
  A: Steam 版 MHW + 冰原 v15.20+。学习版/其他平台版因内存地址不同，不保证可用。

【适用范围】
  生效：狩猎/讨伐/捕获、调查、活动、历战、竞技场/斗技大会/挑战、采集交付等所有正常任务。
  不生效：探索（自由探索）、聚魔之地（游戏本身不计时）。
